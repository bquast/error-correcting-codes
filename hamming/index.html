Hamming Code Demo

A legible implementation of (7,4) error detection and correction.

Controls

1. Encode Message

Enter a 4-bit message (0s and 1s) to encode into a 7-bit Hamming code.

2. Simulate Transmission Error

Flip a specific bit to simulate noise during transmission.

3. Detect & Correct

Calculate syndromes to find the error position, correct it, and extract original bits.
